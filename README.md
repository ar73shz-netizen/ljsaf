# مدیریت فردی — نسخه به‌روزشده

این مخزن برای ساخت APK اندروید با GitHub Actions آماده شده است.

## ساخت APK
1. فایل ZIP را استخراج کنید و محتویات پوشه پروژه را در ریشه یک مخزن GitHub قرار دهید.
2. تغییرات را روی شاخه `main` یا `master` ارسال کنید.
3. در GitHub وارد زبانه **Actions** شوید.
4. گردش‌کار **Build Android APK** را باز کنید و **Run workflow** را بزنید.
5. پس از موفقیت ساخت، از بخش Artifacts فایل `personal-manager-apk` را دریافت کنید؛ فایل APK داخل آن است.

## ویجت دستور کار
ویجت اندروید به‌صورت Native AppWidget ساخته و در AndroidManifest ثبت می‌شود. پس از نصب APK، یک بار برنامه را باز کنید تا اطلاعات روز جاری به ویجت منتقل شود؛ سپس در صفحه اصلی گوشی، فهرست Widgets را باز کنید و ویجت «دستور کار» یا «مدیریت فردی» را اضافه کنید. در برخی لانچرها نام برنامه به‌جای نام ویجت نمایش داده می‌شود.

## نکته
ساخت APK در این محیط اجرا نشده است؛ فایل APK باید توسط GitHub Actions ساخته شود. اگر ساخت در Actions خطا داد، گزارش همان اجرای ناموفق را ارسال کنید تا خطا بررسی شود.

## اصلاحات تکمیلی
- قابلیت مرتب‌سازی با کشیدن و رهاکردن در فهرست‌ها فعال است؛ فقط کنترل‌های فلش‌دار حذف شده‌اند.
- مجسمه افتخار با وکتور اختصاصی طلایی نمایش داده می‌شود.
- برای هر کار چک‌لیست و دستور کار می‌توان ارزش سکه جداگانه تعیین کرد؛ انجام کار سکه اضافه می‌کند و ثبت ضربدر به اندازه ارزش کامل کار از موجودی کم می‌کند.
- در دستور کار، دکمه «↪» برای موکول‌کردن به تاریخ دیگر اضافه شده و هنگام موکول‌کردن، نصف ارزش سکه کار کسر می‌شود.
- تکمیل همه کارهای چک‌لیست، علاوه بر سکه هر کار، افتخارهای گردن‌آویز، کاپ و مجسمه را مطابق استمرار روزانه فعال می‌کند.
- تکمیل همه کارهای دستور کار فقط صدای تشویق و جمله انگیزشی نشان می‌دهد و جایزه افتخاری جداگانه ندارد.
- برای اتصال ویجت، پلاگین Native در Android ثبت شده و ماژول JavaScript رسمی Capacitor در مرحله ساخت، پیش از همگام‌سازی Android در پوشه وب قرار می‌گیرد.
- دکمه بازگشت اندروید به بخش قبلی برنامه هدایت می‌کند و در صفحه اصلی برنامه را نمی‌بندد.
